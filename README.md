# Jumbotail

🛒 Product Search & Ranking Microservice

This project implements a search and ranking microservice for an e-commerce platform targeting electronics products (mobiles, accessories, gadgets, etc.) for Tier-2 and Tier-3 cities in India.

The service allows:

Storing products in a catalog

Updating product metadata

Searching products using flexible user queries

Ranking results based on relevance, price intent, rating, popularity, and stock

🚀 Tech Stack

Node.js

Express.js

In-memory data store (Array / Map)

REST APIs
